Pulseq Sequence Programming GUI --- File organization ---1. Add these folders to the external folder before compiling   - Base directory (/usr/g/research/cuh/mjg40/TOPPE/)	- Pulseq - 2DGRE/toppe	- Pulseg - pge2/matlab, pulseg, pulseq/matlab, mirt/utilities, nufft, penalty, systems	- Check the compatibility of the toolboxes during compilation and execution. Use MATLAB depfun(‘script.m’) to list all the functions needed from the toolboxes to run the sequence generation and reconstruction scripts. It is recommended to add only the files and functions required.2. The file organization has to be as follows:   - GUI (base directory) 	- config (put scanner hardware configuration cv files here)	- main (put mainPSD.m here)	- write (put writePSD.m here)	- utils (helper functions required to run the mainPSD and writePSD files)	- external (files and functions from external toolboxes)	- recon (functions for reconstructions)3. All errors will be logged in app_log.txt, under the GUI folder. --- Compilation ---1. Use the “Application Compiler” function in MATLAB 2. Add all the folders to “files required to run the app”3. Compilation needs to be done on a Linux machine with a MATLAB version that matches the one on the scanner. Here we used OpenSUSE Leap 15.6 and MATLAB R2022a4. Save the executable from the file_for_distrubution folder after the compilation is done5. Recompilation is needed if changes are made to the Pulseq scripts--- Setup on the scanner ---1. Text files that facilitate the GUI. Add these files to the main working directory.a. app_config.txt: This file records the changes made to variables through the sequence generation. The number of dummy scans (dda), number of gain calibration scans (pislquant), .entry file number (entryNo), and number of interleaves (nint) are recorded in this file. These variable values will update the values in the EPIC sequence source file (pulseq.e) during scans. Note that changes to the pulseq.e file need to be made to take in this fileb. app_path.txt: this file records and autofills the paths on the GUI. The following paths are recorded in this file: i. run_dir: the main directory where the EPIC, .entry, and .pge files are storedii. config_dir: the directory where the configuration files of the scanner are storediii. recon_dir: where the GRE data is storediv. pge_dir: essentially the same as run_dirv. rdsexe_dir: the directory where the RDS tool locatesvi. spiral_recon_dir: where the spiral data and ksp files are storedvii. rds_data_dir: where the RDS data is written to--- Running the app ---Sequence generation1. After starting the app, change the base directory to the GUI folder. Press Set Directory.2. The default base directory can be changed to other ones later. The default parameters will be loaded when the app is launched.3. Select scanner configuration files with Add Config Files. Press Merge Config.4. Select a mainPSD file.5. Enter a sequence name and an entry file value. 6. Check all the parameter values.7. Press Generate PSD. 8. Press Refresh or Reset if needed. 9. Press Plot kspace Trajectory or Plot Sequence Diagram to plot the trajectory or waveforms.10. The output .seq, .pge, .entry, .ksp, and .B0ksp files will be saved in the pge_dir directory.GRE Reconstruction1. Acquire RDS raw data with ./RDSclient64 -f 4 -k -n all -o XXX.txt. Name XXX as desired. Currently, the RDS is in the Executables directory2. Recon Directory is the directory where the RDS raw data is saved3. Press Set Recon Directory and Refresh RDS, and select RDS data from the drop down menu4. Enter the number of gain calibration scans in the Prescan slot5. Press Run GRE Recon to reconstruct images6. To compare with the product GRE data, acquire the product RDS raw data with: ./RDSclient64 -f 4 -k -n all -o productGreOut.txt7. Change the Prescan value to 0 (product data does not include calibration data) and press Compare with ProductSpiral Reconstruction (currently only ScanArchive file reconstruction without B0 correction is enabled on the scanner)1. Set Spiral Recon Path to where the ScanArchive files are 2. Select the ScanArchive, ksp, B0ksp, and/or the dual echo GRE file3. Enter all the parameter values4. Leave B0 shots 0 to reconstruct without B0 correction5. Press Run Spiral Recon ScanArchive to reconstruct --- Code changes ---1. validate.m from the Pulseg packagePulseg\pge2\matlab\_pge2\validate.mLine 243% AK replaced the rmse function with explicit calculation% since rmse is not supported on 2022a% err = 100 * rmse(abs(tmp_rf_psq(:)), abs(tmp_rf_seq(:))) / rmse(tmp_rf_psq(:), 0*tmp_rf_seq(:));err = 100 * sqrt(mean((abs(tmp_rf_psq(:)) - abs(tmp_rf_seq(:))).^2)) / sqrt(mean((tmp_rf_psq(:) - 0*tmp_rf_seq(:)).^2));
